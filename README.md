# Netflix Project - 1ª Iteração

Sistema acadêmico simples para demonstração da fase de construção.

## Funcionalidades
- Cadastro de usuário
- Login
- Pesquisa de filmes e séries
- Visualização de detalhes
- Avaliação de títulos
- Favoritos
- Área administrativa
- Gerenciamento simplificado de usuários e conteúdos

## Como executar
1. Extraia o arquivo ZIP.
2. Abra o arquivo `index.html` no navegador.
3. Para testar como administrador:
   - E-mail: admin@netflix.com
   - Senha: 1234
4. Para testar como usuário:
   - E-mail: user@netflix.com
   - Senha: 1234

Os dados são armazenados localmente no navegador para facilitar a demonstração.

## Observação
Esta é uma implementação acadêmica simples para a 1ª iteração. Não utiliza servidor ou banco de dados remoto.
